# ADR-0001: Product identity and upstream baseline

- Status: Accepted
- Date: 2026-11-22

## Context

herdr-t3 is a new personal project. It reuses design material from T3 Code
(MIT) and protocol knowledge from Ovis (MIT), and it is operated under
`rebuildup/project-init`'s release-driven model with installation managed by
`rebuildup/pc-setup`.

## Decision

- Product/repository name: **herdr-t3** (`rebuildup/herdr-t3`, public, MIT).
- The project is a separate product. It is not affiliated with T3 Tools Inc.
  or the Ovis project, and it must not present itself as T3 Code.
- All reused code and design material is credited in `THIRD_PARTY_NOTICES.md`;
  vendored files keep upstream license headers where they carry them.
- The upstream commits verified during initial design are pinned in
  `docs/upstream.md`. Ports re-baseline explicitly, never silently.

## Consequences

- Naming, branding, and store/desktop metadata must not reuse T3 Code's name,
  iconography, or visual identity beyond the licensed design tokens and
  primitives themselves.
- License compliance is a review item for every vendored file.
